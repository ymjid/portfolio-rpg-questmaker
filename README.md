# Portfolio RPG — QuestMaker

## 🎮 Description
A CMS built with Angular to manage the data of Portfolio RPG.
Allows editing quests, skills, gear, character and settings,
then exporting a data.json file to update the portfolio.
Built as my second Angular project, mentored by Claude (Anthropic) throughout the development process.

## ✨ Features
- Dashboard with portfolio status (online/offline, last release, commit feed)
- Manage quests with subquests, tags, images and themes
- Manage skills with rating system
- Manage gear inventory
- Manage character profile
- Manage tags and themes
- Export data as data.json
- Terminal/machine visual theme with neon cursor

## 🛠️ Technologies
- Angular 20
- TypeScript
- SCSS
- @ng-icons 32

## 🚀 Launch project

**Prerequisites**
- Node.js >= 22
- Angular CLI

**Installation**
npm install
ng serve
